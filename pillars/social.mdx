Connect a business's Facebook page, Instagram and TikTok once, then create,
schedule and publish posts through the API, the admin or the hosted
connector. Media are the photos and videos you supply, or ads and reels
crafted for the brand. We don't offer AI image or video creation. We craft
finished static ads and reels for your brand.

## What this gives you

- **Connected accounts**: Facebook pages, Instagram and TikTok, connected with
  the owner's own login (OAuth). Never passwords.
- **Posts** with per-platform text (`facebook_content`, `instagram_content`,
  `tiktok_content`), one image (`media_url`), a carousel (`media_urls`, up to
  10) or a video.
- **Scheduling and publishing**, with per-platform results. TikTok videos go
  to the creator's TikTok inbox as drafts by default (`tiktok_mode: "inbox"`).
- **Captions by Neural Draft** (`type: "ai"`, 2 credits): text only.

## Quick example

<CodeGroup>

```bash cURL
curl -X POST https://api.neuraldraft.io/v1/social-posts \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "manual",
    "title": "Saturday sourdough workshop",
    "platforms": ["facebook", "instagram"],
    "facebook_content": "Two seats left for Saturday. Book on our site.",
    "instagram_content": "Two seats left for Saturday 🍞 Link in bio.",
    "media_url": "https://cdn.example.com/workshop.jpg",
    "link_url": "https://linden-bakery.neuraldraft.io/book",
    "status": "scheduled",
    "scheduled_at": "2026-10-24T09:00:00Z"
  }'
```

```ts SDK
const post = await nd.social.createPost({
  title: "Saturday sourdough workshop",
  platforms: ["facebook", "instagram"],
  facebook_content: "Two seats left for Saturday. Book on our site.",
  instagram_content: "Two seats left for Saturday. Link in bio.",
  media_url: "https://cdn.example.com/workshop.jpg",
  status: "scheduled",
  scheduled_at: "2026-10-24T09:00:00Z",
  external_ref: "workshop-2026-10-24", // same ref = same post, safe to resend
});
```

</CodeGroup>

Creating, scheduling and publishing use no credits. `POST /v1/social-posts/batch`
creates up to 50 posts in one call (each with an `external_ref` so re-sending
is safe).

## Common workflows

### Connect an account

```bash
curl -X POST https://api.neuraldraft.io/v1/social-accounts/connect/instagram \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY"
```

Returns an OAuth URL for the owner to open. If the login manages several
Facebook pages, list them with `GET /v1/social-accounts` and choose one with
`POST /v1/social-accounts/{id}/page`.

### Captions written by Neural Draft

```bash
curl -X POST https://api.neuraldraft.io/v1/social-posts \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"ai","topic":"Our new seeded rye","platforms":["facebook","instagram"],"tone":"warm"}'
```

Returns a [job](/api-reference#tag/Jobs); the post is saved as a draft with
text only (2 credits, `social_post`). Add your own media with `PATCH` before
scheduling.

### Schedule, move, cancel, publish now

- `POST /v1/social-posts/{id}/schedule` with `scheduled_at`
- `PATCH /v1/social-posts/{id}` with a new `scheduled_at`, or `status: "draft"`
  to take it off the queue (nothing is deleted)
- `POST /v1/social-posts/{id}/publish` publishes immediately

Subscribe to `social_post.published` and `social_post.failed`
[webhooks](/webhooks) for the outcome.

## Reference

| Endpoint | |
| --- | --- |
| `GET /v1/social-posts`, `GET /v1/social-posts/{id}` | list, one post with per-platform status |
| `POST /v1/social-posts`, `POST /v1/social-posts/batch` | create |
| `PATCH /v1/social-posts/{id}`, `DELETE /v1/social-posts/{id}` | update, delete |
| `POST /v1/social-posts/{id}/schedule`, `/publish` | schedule, publish now |
| `GET /v1/social-accounts` | connected accounts |
| `POST /v1/social-accounts/connect/{platform}` | start OAuth |
| `POST /v1/social-accounts/{id}/page`, `DELETE /v1/social-accounts/{id}` | choose Facebook page, disconnect |
