Customers book a time (appointments, classes, consultations) or a date range
(rentals, stays) on the site. Bookings are part of Solo, Studio and agency
client workspaces and use no credits.

The quickest path is the block, which works on hosted sites and, with the
origin allowed, on [sites hosted elsewhere](/guides/embeds-and-cors):

```html
<script src="/_nd/nd.js" defer></script>
<nd-booking service="consultation"></nd-booking>
```

The workspace also has a hosted booking page on its address.

## Set up a service

<CodeGroup>

```bash cURL
curl -X POST https://api.neuraldraft.io/v1/bookable-services \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Sourdough workshop",
    "booking_type": "time_slot",
    "duration_minutes": 120,
    "price": 4500,
    "currency": "gbp",
    "max_bookings_per_slot": 8,
    "min_notice_hours": 24,
    "status": "active"
  }'
```

```ts SDK
const service = await nd.booking.createService({
  name: "Sourdough workshop",
  booking_type: "time_slot",
  duration_minutes: 120,
  price: 4500,
  currency: "gbp",
  max_bookings_per_slot: 8,
});
```

</CodeGroup>

Other fields: `buffer_before_minutes`, `buffer_after_minutes`,
`max_advance_days`, `cancellation_hours`, `min_nights` / `max_nights` (for
`date_range`), `images`, `color`. Opening hours and blocked dates are set in
the admin (Customers → Bookings) or with `set_availability` on the
[hosted connector](/guides/hosted-connector). Workspace-wide settings:
`GET/PATCH /v1/booking/settings`.

## Availability and booking (public, no key)

```bash
# Free times for a service
curl "https://api.neuraldraft.io/v1/public/availability?project_id=$PROJECT_ID&service_id=12&from=2026-10-20&to=2026-10-26"

# Book one
curl -X POST "https://api.neuraldraft.io/v1/public/bookings?project_id=$PROJECT_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "service_id": 12,
    "starts_at": "2026-10-24T10:00:00+01:00",
    "customer_name": "Oliver Bennett",
    "customer_email": "oliver@example.com",
    "customer_notes": "Two people"
  }'

# Look it up later
curl "https://api.neuraldraft.io/v1/public/bookings/BK-20261024-AB12?project_id=$PROJECT_ID&email=oliver@example.com"
```

These endpoints are rate limited per IP (5 a minute). A slot taken in the
meantime returns `409 slot_unavailable`: refresh availability and let the
customer pick again.

## Manage bookings (API key)

<CodeGroup>

```bash cURL
curl "https://api.neuraldraft.io/v1/bookings?status=pending" \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY"

curl -X POST https://api.neuraldraft.io/v1/bookings/452/confirm \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY"
```

```ts SDK
const { data: upcoming } = await nd.bookings.list({ status: "confirmed" });
await nd.bookings.confirm(452);
await nd.bookings.cancel(453);
```

</CodeGroup>

Lifecycle: `confirm`, `cancel`, `complete`, `no-show`. Also
`GET /v1/bookings/calendar`, `GET /v1/bookings/stats`, and an admin-side lookup
`GET /v1/availability?service_id=&from=&to=`. Webhooks: `booking.confirmed`,
`booking.cancelled`, `booking.completed`.

Calendar export: each workspace has a private iCal feed
(`/v1/public/calendar/{token}.ics`) for Google or Apple Calendar; find the
link in the admin.

| Endpoint | Scope |
| --- | --- |
| `GET/POST /v1/bookable-services`, `GET/PATCH/DELETE /v1/bookable-services/{id}` | `booking:read` / `booking:write` |
| `GET /v1/availability` | `booking:read` |
| `GET/PATCH /v1/booking/settings` | `booking:read` / `booking:write` |
| `GET/POST /v1/bookings`, `GET/PATCH/DELETE /v1/bookings/{id}` | `booking:read` / `booking:write` |
| `POST /v1/bookings/{id}/confirm` | `booking:confirm` |
| `POST /v1/bookings/{id}/cancel` | `booking:cancel` |
| `POST /v1/bookings/{id}/complete`, `/no-show` | `booking:write` |
| `GET /v1/bookings/calendar`, `/stats` | `booking:read` |
| `GET /v1/public/availability`, `GET /v1/public/services/{id}`, `POST /v1/public/bookings`, `GET /v1/public/bookings/{ref}` | none (`?project_id=`) |
