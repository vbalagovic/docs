The shop is part of every Solo, Studio and agency client workspace. Customers
buy on the hosted shop page or through the `<nd-shop>` / `<nd-product>`
blocks; you manage the catalogue and orders in the admin, the hosted
connector, or the API below. Payment options and connecting Stripe:
[Shop and payments](/guides/shop-and-payments).

## What this gives you

- **Products** with variants, categories, stock tracking and pictures.
- **Orders** with status (`pending → paid → processing → shipped → delivered`,
  or `cancelled` / `refunded`) and refunds for card payments.
- **Checkout** on the site: pay on pickup, bank transfer, order request, or card
  once Stripe is connected.
- **Public catalogue** endpoints for headless storefronts.

## Products

<CodeGroup>

```bash cURL
curl -X POST https://api.neuraldraft.io/v1/products \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
    "name": "Seeded rye",
    "price": 520,
    "currency": "gbp",
    "status": "active",
    "track_inventory": true,
    "stock_quantity": 24,
    "images": ["https://cdn.example.com/rye.jpg"]
  }'
```

```ts SDK
const rye = await nd.products.create({
  name: "Seeded rye",
  price: 520, // minor units
  currency: "gbp",
  status: "active",
  track_inventory: true,
  stock_quantity: 24,
});
await nd.products.update(rye.id, { stock_quantity: 20 });

const { data: products } = await nd.products.list({ status: "active", page_size: 50 });
```

</CodeGroup>

`price` is an integer in minor units (pence, cents). `slug` is derived from
the name if you don't send one.

### Variants and categories

```bash
curl -X POST https://api.neuraldraft.io/v1/products/42/variants \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Large","sku":"RYE-L","price":780,"stock_quantity":10}'
```

Categories: `GET/POST /v1/product-categories`, `GET/PATCH/DELETE /v1/product-categories/{id}`.
In the SDK: `nd.products.listVariants/createVariant/updateVariant/deleteVariant`
and `nd.productCategories.*`.

## Orders

```bash
# Paid orders this week
curl "https://api.neuraldraft.io/v1/orders?payment_status=paid&from=2026-10-12" \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY"

# Mark one shipped
curl -X PATCH https://api.neuraldraft.io/v1/orders/902 \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"status":"shipped"}'

# Refund a card payment (amount optional, minor units)
curl -X POST https://api.neuraldraft.io/v1/orders/902/refund \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"amount":520}'
```

Webhooks: `order.created`, `order.paid`, `order.fulfilled`, `order.cancelled`,
`order.refunded`. See [Webhooks](/webhooks).

## On the site

```html
<script src="/_nd/nd.js" defer></script>
<nd-shop></nd-shop>
<nd-product id="seeded-rye"></nd-product>
```

On a site hosted elsewhere, load `nd.js` from the workspace address and allow
the site's origin, or use the iframe embed. See
[Embeds and CORS](/guides/embeds-and-cors).

For a fully custom storefront, read the catalogue without a key:
`GET /v1/public/products?project_id=…`, `GET /v1/public/products/{id_or_slug}`,
`GET /v1/public/product-categories`, and look up an order with
`GET /v1/public/orders/{order_number}`.

## Reference

| Endpoint | Scope |
| --- | --- |
| `GET/POST /v1/products`, `GET /v1/products/{id_or_slug}`, `PATCH/DELETE /v1/products/{id}` | `commerce:read` / `commerce:write` |
| `/v1/products/{id}/variants[/{variant_id}]` | `commerce:read` / `commerce:write` |
| `/v1/product-categories[/{id}]` | `commerce:read` / `commerce:write` |
| `GET /v1/orders`, `GET /v1/orders/{id_or_number}` | `orders:read` |
| `PATCH /v1/orders/{id}` | `orders:write` |
| `POST /v1/orders/{id}/refund` | `orders:refund` |
| `GET /v1/public/products`, `/v1/public/product-categories`, `/v1/public/orders/{number}` | none |
