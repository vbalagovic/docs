Neural Draft speaks the Model Context Protocol in two ways.

<CardGroup cols={2}>
  <Card title="Hosted connector" icon="cloud" href="/guides/hosted-connector">
    `https://neuraldraft.io/mcp`. Remote, OAuth sign-in. Claude, ChatGPT,
    Codex, Claude Code, Cursor, VS Code. Builds, deploys and edits the hosted
    site, domains, blog, bookings, socials, ads.
  </Card>
  <Card title="Developer MCP" icon="terminal" href="/mcp/setup">
    `@neuraldraft/mcp` on npm (MIT). Local stdio via `npx`, one API key per
    workspace, several keys for agencies. Wires a codebase to the API while
    your assistant writes code.
  </Card>
</CardGroup>

## What `@neuraldraft/mcp` exposes

### Resources

| URI | What it is |
| --- | --- |
| `brand://current` | Voice, audience, colours, fonts, languages. Read before generating UI. |
| `schema://blog-post` | Blog post response shape. |
| `schema://product` | Product and variant shape. |
| `schema://booking` | Services, bookings, availability. |
| `conventions://editable-html` | The `data-translate` / `data-image-key` rules. See [Editable markup](/guides/editable-markup). |
| `conventions://api-usage` | Auth, errors, rate limits, jobs. |

### Tools

| Group | Tools |
| --- | --- |
| Workspaces | `list_workspaces`, `switch_workspace` ([several workspaces](/mcp/multi-workspace)), `find_workspaces` |
| Brand | `get_brand`, `update_brand` |
| Content | `create_translation_keys`, `get_content`, `list_content`, `delete_content`, `register_component`, `delete_component` |
| Pages | `create_page`, `list_pages`, `get_page`, `update_page`, `delete_page` |
| Images and galleries | `list_images`, `get_image`, `register_image`, `replace_image` (by URL), `delete_image`, `list_galleries`, `get_gallery`, `create_gallery`, `update_gallery`, `delete_gallery` |
| Blog | `generate_blog_post`, `list_blog_posts`, `get_blog_post`, `update_blog_post` |
| Booking and shop | `create_bookable_service`, `setup_booking_widget`, `list_products`, `get_product` |
| Forms | `list_newsletter_subscribers`, `list_contact_form_submissions` |
| Account | `get_usage`, `get_job` |

`generate_image` and `generate_video` are still in the package but the API
answers them with `410 media_generation_moved`. We don't offer AI image or
video creation. We craft finished static ads and reels for your brand
(through the hosted connector).

### Prompts

| Prompt | What it does |
| --- | --- |
| `/scaffold-marketing-site` | A full marketing site wired to Neural Draft (brand, editable keys, components). |
| `/scaffold-blog-page` | A `/blog` index and post page in an existing project. |
| `/connect-existing-site` | Make an existing static site editable through Neural Draft. |

## What the developer MCP doesn't do

Hosting tools (`deploy_site`, `rollback_site`, `connect_custom_domain`,
`publish_site_page`, `list_site_texts` / `update_site_text`, `get_embed_snippet`)
are on the hosted connector. Add both to Claude Code or Codex when you want to
build and deploy in one session.

## Tools without MCP

Coding tools that can't run MCP servers can still follow the same conventions
with a prompt block: see [Other AI builders](/frameworks/lovable).
