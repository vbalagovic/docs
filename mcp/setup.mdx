`@neuraldraft/mcp` is a stdio server you run with `npx`. You need Node 20+, a
workspace API key (admin → Settings → For developers → API keys) and an MCP
client.

<Tip>
  Want hosting, deploys and domains too? Also add the
  [hosted connector](/guides/hosted-connector) (`https://neuraldraft.io/mcp`).
</Tip>

## Claude Code

```bash
claude mcp add neuraldraft-dev -e NEURALDRAFT_API_KEY=ndsk_live_... -- npx -y @neuraldraft/mcp
```

Add `--scope project` to write it to the project's `.mcp.json` (keep the key
out of git with an env reference) or edit the file by hand:

```json .mcp.json
{
  "mcpServers": {
    "neuraldraft-dev": {
      "command": "npx",
      "args": ["-y", "@neuraldraft/mcp"],
      "env": { "NEURALDRAFT_API_KEY": "${NEURALDRAFT_API_KEY}" }
    }
  }
}
```

Run `/mcp` to check it's connected.

## Codex

```bash
codex mcp add neuraldraft-dev --env NEURALDRAFT_API_KEY=ndsk_live_... -- npx -y @neuraldraft/mcp
```

or in `~/.codex/config.toml`:

```toml
[mcp_servers.neuraldraft-dev]
command = "npx"
args = ["-y", "@neuraldraft/mcp"]
env = { NEURALDRAFT_API_KEY = "ndsk_live_..." }
```

## Continue

`~/.continue/config.yaml`:

```yaml
mcpServers:
  - name: neuraldraft-dev
    command: npx
    args: ["-y", "@neuraldraft/mcp"]
    env:
      NEURALDRAFT_API_KEY: ndsk_live_...
```

## Environment variables

| Variable | Required | Notes |
| --- | --- | --- |
| `NEURALDRAFT_API_KEY` | one of these two | One workspace key, `ndsk_live_…`. |
| `NEURALDRAFT_API_KEYS` | one of these two | Several workspaces: `client-a=ndsk_live_…,client-b=ndsk_live_…` or a JSON object. See [Several workspaces](/mcp/multi-workspace). |
| `NEURALDRAFT_WORKSPACE` | no | Which of `NEURALDRAFT_API_KEYS` is active at start (default: the first). |
| `NEURALDRAFT_API_URL` | no | Default `https://api.neuraldraft.io/v1`. |
| `NEURALDRAFT_DISPLAY_NAME` | no | Friendly name in your client's server list. |

`NEURAL_DRAFT_*` spellings are accepted as aliases. A missing or malformed key
fails at start with a message showing a working config.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Server not listed | Restart the client; check `npx -y @neuraldraft/mcp` runs in a terminal (Node 20+). |
| `401 invalid_api_key` | The key was revoked or mistyped; create a new one. |
| `403 insufficient_scope` | Give the key the scope (or full access). |
| `410 media_generation_moved` | `generate_image` / `generate_video` are retired; use uploads, `register_image` or the hosted connector's ads. |
