Claude Code, Codex, Cursor, VS Code, Claude and ChatGPT connect to Neural Draft
directly (see [Hosted connector](/guides/hosted-connector) and
[MCP setup](/mcp/setup)). For builders that can't add MCP servers, paste the
block below into their project instructions. It teaches the same conventions.
You can also build there, export the code, and deploy it with `deploy_site`
from Claude Code or Codex.

## Copy this

````md
This site uses **Neural Draft** for hosting-side features: editable content,
blog, bookings, forms, newsletter and shop. Follow these rules.

# Workspace
- Workspace address: https://{workspace}.neuraldraft.io
- API base (server-side only, key in env NEURALDRAFT_API_KEY): https://api.neuraldraft.io/v1

# Editable content
1. Every visible text gets data-translate="section.field" (lowercase, dots, e.g.
   hero.title, menu.2.price). Keys are unique per meaning.
2. Every image gets data-image-key="key" and a real alt text.
3. Default copy goes inside the element; Neural Draft stores it on deploy and the
   owner edits it later without code.

# Features (no API key in the browser)
Load once: <script src="https://{workspace}.neuraldraft.io/_nd/nd.js" defer></script>
- Booking: <nd-booking service="{service-slug}"></nd-booking>
- Contact form: <nd-form id="contact"></nd-form>
- Newsletter: <nd-newsletter></nd-newsletter>
- Latest posts: <nd-blog-feed limit="3"></nd-blog-feed>
- Shop: <nd-shop></nd-shop> or <nd-product id="{product-slug}"></nd-product>
Theme with CSS variables --nd-primary, --nd-surface, --nd-text, --nd-radius.

# Server-side reads (build time or server functions only)
- Texts: GET /v1/content/bulk?keys=a,b&lang=en
- Pages and SEO meta: GET /v1/pages/{slug}
- Blog: GET /v1/blog-posts?status=published&lang=en, GET /v1/blog-posts/{slug}
- Products (no key): GET /v1/public/products?project_id={id}

# Don't
- Don't put the API key in browser code.
- Don't invent endpoints; the reference is https://docs.neuraldraft.io/api-reference.
- Don't hard-code text that the owner will want to change.
````

When the site is hosted elsewhere, add its address to the workspace's allowed
websites so `nd.js` can call the workspace (see
[Embeds and CORS](/guides/embeds-and-cors)).

## Server-side glue

```ts lib/neuraldraft.ts
import { NeuralDraftClient } from "@neuraldraft/sdk";

export const nd = new NeuralDraftClient({ apiKey: process.env.NEURALDRAFT_API_KEY! });

export async function homeMeta() {
  const page = await nd.pages.get("home");
  return { title: page.meta_title ?? page.title, description: page.meta_description };
}
```
