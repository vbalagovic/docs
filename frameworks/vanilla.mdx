## On a Neural Draft hosted site

Deploy the folder with `deploy_site` (see [Hosted sites](/guides/hosted-sites)).
Mark texts and pictures, add blocks:

```html index.html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>Linden Bakery</title>
    <script src="/_nd/nd.js" defer></script>
  </head>
  <body>
    <h1 data-translate="hero.title">Fresh bread every morning</h1>
    <p><nd-text key="hours">Mon–Sat 7:00–15:00</nd-text></p>
    <img data-image-key="hero" src="/img/hero.jpg" alt="Our bakery" />

    <nd-booking service="sourdough-workshop"></nd-booking>
    <nd-form id="contact"></nd-form>
    <nd-newsletter></nd-newsletter>
  </body>
</html>
```

Values are filled on the server; the client edits them in the admin or by
chat. No key in the page.

## On a site hosted elsewhere

Load `nd.js` from the workspace address and allow your site's origin
([Embeds and CORS](/guides/embeds-and-cors)):

```html
<script src="https://linden-bakery.neuraldraft.io/_nd/nd.js" defer></script>
<nd-booking service="sourdough-workshop"></nd-booking>
<nd-form id="contact"></nd-form>
```

Editable texts on an external site: render them server-side from
`GET /v1/content/bulk` (below), or let `nd.js` fill `data-translate` /
`<nd-text>` blocks in the browser.

## The JS API

```html
<script>
  window.addEventListener("load", async () => {
    const { services } = await ND.getServices();
    const slots = await ND.getSlots("sourdough-workshop", "2026-10-24");
    const posts = await ND.getPosts({ limit: 3 });
    console.log(services, slots, posts);
  });
</script>
```

Also `ND.submitForm(id, fields)`, `ND.subscribe(email)`, `ND.book({...})`,
`ND.getShop()`, `ND.applyContent(root)`.

## A server-side call (Node script, cron)

```js fetch-content.mjs
const res = await fetch(
  "https://api.neuraldraft.io/v1/content/bulk?keys=hero.title,hours&lang=en",
  { headers: { Authorization: `Bearer ${process.env.NEURALDRAFT_API_KEY}` } },
);
const texts = await res.json();
console.log(texts); // { "hero.title": "...", "hours": "..." }
```

Never ship the API key to the browser.

## Hand this to your AI

> Build this page as plain HTML. Mark every visible text with
> `data-translate="section.field"` and every image with `data-image-key`.
> Load `/_nd/nd.js` and use `<nd-booking>`, `<nd-form>` and `<nd-newsletter>`
> for the booking, contact and sign-up parts. Then deploy the folder to Neural
> Draft with deploy_site.
