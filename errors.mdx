Errors from `/v1` are JSON. Branch on `status` and `code`; `title` and
`detail` are for humans.

## Shape

```json
{
  "type": "https://neuraldraft.com/errors/insufficient-scope",
  "title": "Forbidden",
  "status": 403,
  "detail": "This API key does not have the required scope: blog:write.",
  "code": "insufficient_scope",
  "required_scope": "blog:write"
}
```

Validation errors (`422`) use the standard shape with a `message` and an
`errors` map keyed by field:

```json
{
  "message": "The slug field is required. (and 1 more error)",
  "errors": {
    "slug": ["The slug field is required."],
    "title": ["The title field is required."]
  }
}
```

## Codes

| HTTP | `code` | Meaning | Retry? |
| --- | --- | --- | --- |
| `400` | `bad_request` | Malformed request. | No |
| `401` | `missing_api_key`, `invalid_api_key`, `revoked_api_key`, `expired_api_key` | No usable key. See [Authentication](/authentication). | No |
| `402` | `insufficient_credits` | Not enough credits for this AI work. Body has `cost` and `balance`. | After a top-up |
| `403` | `insufficient_scope` | The key lacks the scope (`required_scope`). | No |
| `403` | `project_not_provisioned` | The workspace isn't ready yet. | Later |
| `403` | `origin_not_allowed` | `nd.js` `POST` from a website that isn't allowed. See [Embeds and CORS](/guides/embeds-and-cors). | No |
| `404` | `not_found`, `page_not_found`, `job_not_found` | Doesn't exist in this workspace. | No |
| `409` | `slug_taken` | Slug already used. | No |
| `409` | `slot_unavailable` | The booking slot was taken in the meantime. | Refresh availability, let the user pick |
| `409` | `invalid_state_transition`, `job_already_terminal` | The resource can't move to that state. | No |
| `409` | `connect_not_ready` | Card payments aren't set up for this shop. | No |
| `410` | `media_generation_moved` | AI image and video generation endpoints are retired. | No |
| `422` | (validation) | See `errors`. | No |
| `422` | `unprocessable`, `order_not_refundable`, `service_has_upcoming_bookings` | The request is valid but can't be done. | No |
| `429` | `rate_limit_exceeded` | Over 60 requests a minute for this key. `retry_after` in the body. | Yes, after `Retry-After` |
| `5xx` | | Server or upstream problem. | Yes, with backoff |

### `insufficient_credits`

Only AI work done by Neural Draft uses credits (blog posts, translations, ads,
reels, App Capture). Content, page and image writes are free.

```json
{
  "type": "https://neuraldraft.com/errors/payment-required",
  "title": "Payment Required",
  "status": 402,
  "detail": "Insufficient credits.",
  "code": "insufficient_credits",
  "cost": 60,
  "balance": 12
}
```

### `media_generation_moved`

`POST /v1/images` with a `prompt`, image regeneration, and `POST /v1/videos`
return `410`. We don't offer AI image or video creation. We craft finished
static ads and reels for your brand. Uploading an image or registering one by
URL still works.

## Retry strategy

Retry only `429` and `5xx`, with exponential backoff and jitter, at most 5
times, and always honour `Retry-After`.

```ts
async function withRetry<T>(fn: () => Promise<T>, max = 5): Promise<T> {
  for (let attempt = 0; ; attempt++) {
    try {
      return await fn();
    } catch (err: any) {
      const retryable = err?.status === 429 || err?.status >= 500;
      if (!retryable || attempt + 1 >= max) throw err;
      const after = Number(JSON.parse(err?.body || "{}").retry_after);
      const delay = Number.isFinite(after) ? after * 1000 : Math.random() * Math.min(30_000, 250 * 2 ** attempt);
      await new Promise((r) => setTimeout(r, delay));
    }
  }
}
```

The SDK throws `ApiError` with `status`, `path` and `body` (the raw JSON
response; parse it for `code`). `status: 0` means a network failure or timeout.

## Idempotency

`POST /v1/products`, order updates and refunds, and `POST /v1/checkout-sessions`
accept an `Idempotency-Key` header. A retry with the same key on the same
route within 24 hours returns the original response instead of doing the work
again.

```bash
curl -X POST https://api.neuraldraft.io/v1/products \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"name":"Seeded rye","price":520,"currency":"gbp"}'
```
