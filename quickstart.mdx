---
title: "Quickstart"
description: "A workspace, an API key, your first API call, then Neural Draft in your AI assistant."
---

<Steps>
  <Step title="Create a workspace">
    Sign up at [app.neuraldraft.io/register](https://app.neuraldraft.io/register)
    (or add the [hosted connector](/guides/hosted-connector) to Claude or
    ChatGPT and sign in: new accounts get a free workspace). Your site is live
    at `<name>.neuraldraft.io` from the start.
  </Step>

  <Step title="Create an API key">
    In the admin open **Settings → For developers → API keys → Create key**.
    Give it a name (`vercel-prod`, `claude-code-laptop`) and either full access
    or only the [scopes](/authentication#scopes) it needs.

    Keys look like `ndsk_live_…`, are shown **once**, and only reach their own
    workspace. Keep them server-side.

    ```bash
    export NEURALDRAFT_API_KEY=ndsk_live_...
    ```
  </Step>

  <Step title="Make a call">
    <CodeGroup>

    ```bash cURL
    curl https://api.neuraldraft.io/v1/projects/me \
      -H "Authorization: Bearer $NEURALDRAFT_API_KEY"

    # Read the site's editable texts (the same values clients edit)
    curl "https://api.neuraldraft.io/v1/content?lang=en&page_size=20" \
      -H "Authorization: Bearer $NEURALDRAFT_API_KEY"
    ```

    ```ts SDK
    // npm install @neuraldraft/sdk
    import { NeuralDraftClient } from "@neuraldraft/sdk";

    const nd = new NeuralDraftClient({ apiKey: process.env.NEURALDRAFT_API_KEY! });

    const me = await nd.projects.me();
    console.log(`Hello, ${me.name} (${me.domain})`);

    // A draft blog post you wrote yourself: free
    const post = await nd.blogPosts.create({
      title: "Five things we shipped this week",
      content: "<p>It was a busy week.</p>",
      language_code: "en",
      status: "draft",
    });
    console.log(post.slug);
    ```

    </CodeGroup>
  </Step>

  <Step title="Add Neural Draft to your AI assistant">
    Two options, and you can use both.

    **Hosted connector** (sign in, no key): build, deploy and edit the hosted
    site, connect a domain, blog, bookings.

    ```bash
    claude mcp add --transport http neuraldraft https://neuraldraft.io/mcp
    # Codex:
    codex mcp add neuraldraft --url https://neuraldraft.io/mcp && codex mcp login neuraldraft
    ```

    **Developer MCP** (`@neuraldraft/mcp`, uses your API key): brand context,
    pages, content keys, components, galleries, blog, bookings while you code.

    ```bash
    claude mcp add neuraldraft-dev -e NEURALDRAFT_API_KEY=$NEURALDRAFT_API_KEY -- npx -y @neuraldraft/mcp
    ```

    Then ask: *"Build the site in this folder, mark the texts editable, and
    deploy dist/ to Neural Draft with deploy_site."* See
    [Hosted sites](/guides/hosted-sites) and [MCP setup](/mcp/setup).
  </Step>
</Steps>
