Neural Draft is the backend and hosting for websites built with AI. You (or
your AI assistant) design and build the site. Neural Draft hosts it, keeps its
texts and pictures editable, and adds the parts a business needs: a blog,
bookings, forms, a newsletter, a shop, languages, your own domain with HTTPS,
and social publishing.

Every workspace is one business, with its own database. A workspace has its
own address (`<name>.neuraldraft.io`), its own API keys and its own admin at
[app.neuraldraft.io](https://app.neuraldraft.io).

## Three ways to build

<CardGroup cols={3}>
  <Card title="Developer MCP" icon="terminal" href="/mcp/setup">
    In **Claude Code, Cursor or Codex**: `@neuraldraft/mcp` with an API key
    reads the brand, creates pages, content keys, galleries and blog posts
    while your assistant writes the code. Agencies can hold every client key
    in one server.
  </Card>
  <Card title="Hosted connector" icon="comments" href="/guides/hosted-connector">
    In **Claude, ChatGPT or Codex** (and Claude Code): add
    `https://neuraldraft.io/mcp` and sign in. No key needed. Build and deploy
    the site, edit texts, connect a domain, write the blog, take bookings.
  </Card>
  <Card title="Your own hosting" icon="server" href="/guides/embeds-and-cors">
    Keep Vercel, Netlify, WordPress or Webflow. Read content with the
    **headless API or the SDK**, and drop in booking, form, newsletter, blog
    and shop blocks with `nd.js`.
  </Card>
</CardGroup>

Most people combine them: build in Claude Code, publish with `deploy_site`
from the hosted connector, and let the client make later changes in the
visual editor or by asking Claude.

## For agencies

One workspace (and one database) per client, an agency dashboard, pooled
credits with a cap per client, and white-label on client sites. The developer
MCP holds every client key in one server. See [Agencies](/guides/agencies).

## Hello, world

<CodeGroup>

```ts SDK
import { NeuralDraftClient } from "@neuraldraft/sdk";

const nd = new NeuralDraftClient({ apiKey: process.env.NEURALDRAFT_API_KEY! });

const me = await nd.projects.me();
const { data: pages } = await nd.pages.list();
console.log(me.name, pages.map((p) => p.slug));
```

```bash cURL
curl https://api.neuraldraft.io/v1/projects/me \
  -H "Authorization: Bearer $NEURALDRAFT_API_KEY"
```

</CodeGroup>

## Pricing in one paragraph

Hosting, pages, deploys, content edits, forms, bookings, the shop and
everything your own AI writes cost **no credits**. Credits (1 credit = $0.01)
are used only when Neural Draft's own pipeline does AI work: a blog post (60),
a translation (10 per language), a crafted static ad (50), a reel (500) or an
App Capture (200). We don't offer AI image or video creation. We craft
finished static ads and reels for your brand. Free starts with 400 credits;
Solo is $49 a month with 3,000; Studio is $149 with 10,000. Details:
[Credits and pricing](/pricing-and-credits).
